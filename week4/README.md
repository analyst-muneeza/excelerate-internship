# Week 4 – Final Presentation

## Overview
This week focuses on the final presentation of the International Student Compliance Analytics project.  
The presentation summarizes the complete analytical journey from data preparation to dashboard insights and institutional recommendations.

## Project Highlights
- Dataset analysis of 34,341 international student records
- Compliance KPI evaluation
- Dashboard walkthrough using Looker Studio
- Trend analysis and key findings
- Data-driven recommendations
- Institutional impact assessment

## Tools & Technologies
- Supabase PostgreSQL
- Google Looker Studio
- SQL
- Data Visualization
- Compliance Analytics

## Key KPIs
- I-20 Issuance Rate
- Deposit Completion Rate
- SEVIS Fee Payment Rate
- Advisor Assignment Rate
- SEVIS Linkage Rate

## Files Included
- Final Presentation PPT/PDF
- Dashboard Screenshots
- Presentation Resources

## Outcome
Developed an end-to-end compliance analytics solution to identify operational gaps, monitor KPIs, and provide actionable recommendations for improving international student compliance processes.
